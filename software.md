# Software

A list of software that can be used for railfanning

- [ITCMon](http://www.github.com/katsojuna/itcmon)
- [PTCTalk Groups.IO group (please do not flood them with new users, request only). Lots of great software is posted here such as ITC Locomotive Tracker, ITCVue, etc.](https://groups.io/g/PTCTalk)
- [ITC Locomotive Tracker (consider becoming a server if your computer can sit idle for days and your area is not covered, request only).](https://itclocotracker.com)
- ITCVue (the link is in the Groups.IO group, request only).
